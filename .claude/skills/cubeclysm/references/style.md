# Cubeclysm 风格规则

Cubeclysm 走 Unturned 的路子：方块做形体，2D 贴图画细节。远看靠剪影认出是谁，近看靠贴图和 3D 小部件讲故事。

## 单位与朝向（库标准）

- 1 单位 = 1 格 = 1 m，+Y 朝上，脸朝 −Z（北），原点在脚底中心。
- 骨骼关节名：`root › body › head / shoulders › upper_arm.L/R › forearm › hand`、`thigh.L/R › shin`。
- 三角面预算只作参考。目前一个丧尸约 200–500 面，骷髅约 1000 面。

## 形体

- **头**：方形，比真人大。`HEAD_OF_TORSO` 约 0.76，脖子很短（`NECK` 0.02，宽度为头的 0.62）。用户先后指出过"脖子太细""脑袋太小"，所以不要往回改小。
- **手**：连指手套式的方块手，不画手指。
- **四肢和躯干**：都是长方体，腿不要太长，标准成人身高约 1.75–1.8 m。
- **体型对应 CDDA 体积**（相对 `mon_zombie` 的 62.5 L）：

| 体型 | 典型目标 | 例子 |
|---|---|---|
| child | 0.5× | 儿童丧尸 31.25 L |
| female / teen / lanky | 约 0.8–1.0× | 苗条、跑者 |
| standard | 1.0× | 绝大多数 62.5 L 的丧尸 |
| tough | 约 1.15–1.3× | 健壮；72.5 L 的凯夫拉丧尸兽 |
| fat | 1.5× | 93.75 L |
| brute | 1.6×（四足时 2.24×） | 100 L / 140 L |
| bloated | 1.75× | 108.5 L 的臃肿、毒气袋、腐蚀 |
| giant | 14× | 875 L 的巨尸 |

穿戴物（防弹背心、头盔、外骨骼）会让模型体积超过官方值，因为 CDDA 的体积不算衣物。比例到 1.4 左右可以接受；更高就要在汇报里说明理由。

## 脸（乐高式印刷脸）

- 脸画在头方块正面，贴图是 128 px 的面部画布。脸由几类部件叠加而成：眼（eyes）、眉（brows）、嘴（mouth）、标记（marks：疤、血、胡茬、腐烂等）。部件存放在 `tools/cubeclysm/faces/<类>/<名>.png`，用关键色按色相重新着色：
  - 品红 → 眼睛颜色
  - 绿 → 眼窝
  - 蓝 → 眉毛/头发
  - 红 → 眼睑
- **一批之内表情要各不相同**。用户批评过"僵尸的脸看起来都一个样"，所以要搭配不同的眼、眉、嘴组合，再加标记。
- 人类用 `h_*` 部件（虹膜、睫毛、雀斑、胡子等）。
- 描述里写了面部变形的，可以用 `face.lift` 移动某一类部件，比如眼睛被挤到额头：`lift: { eyes: -0.22 }`。画布上做不出的变形（凸出的嘴、骨刺牙）用 3D 部件做。
- 骷髅类用 `skull: true`，脸整面换成颅骨。

## 头发

头发是 3D 发型组（`hair.js`，22 种）。带刘海的发型会在脸上额外画一条刘海。光头写 `hair: null`。发型要符合人物身份：军人用寸头，医生用侧分，舞者用马尾，以此类推。

## 服装与贴图

- 衣服是 2D 贴图：先填底色，再画领口、口袋、扣子、迷彩、格子、条纹、反光条、字母等细节。
- 磨损（`wear`）按比例随机分布在身体各部位，包括撕口、血迹、伤口、烟灰、酸蚀、和血肉融合、碎裂纹、锈迹、阴影、纹身等。
- 颜色可以自由选，但同一批之间要容易区分，而且要让人一眼看出职业（警察藏青、消防土黄、医护白/蓝、囚服黑白条纹）。
- 描述里的颜色和图案必须照做，比如"black and white striped""deep blue naval fatigues"。

## 必须做成 3D 的东西

只要描述提到穿戴物或形体异常，就要做成独立方块，**不能只改贴图**：
- 帽子、头盔、面罩、护目镜、夜视仪
- 背心、防弹板、背包、气瓶
- 手铐、听诊器、胸卡
- 肚腩、驼背、肉瘤、囊肿
- 骨甲、骨刺、骨棒、爪子
- 肉管、垃圾、碎片、阴影丝

部件要大到在默认视距下看得清。胆汁士兵的肉管第一版太小太暗，返工过一次。

## 姿势

| 姿势 | 用于 |
|---|---|
| stand | 站立 |
| reach | 经典的伸手蹒跚 |
| hunched | 弓背 |
| crooked | 歪斜 |
| crawl | 爬行者，身体贴地 |
| prowl | 四足，手脚都着地 |
| drag | 手臂后摆，拖地的武器 |

姿势只是一个静态造型，游戏里的走路、攻击等动画另做。改姿势后检查 `lowest`，确认没有穿进地面，也没有悬空。

## 特效（FX）

- 液体、气体、碎屑、鼓动、抖动之类的动态效果，做成名为 **"FX"** 的循环 glTF 动画，周期 2.4 s。
- 特效只能动 `fx_*` 节点，绝不动关节，这样引擎可以把它叠在任何身体动画上。
- 粒子节点挂在它产生的部位上，会跟着该部位移动。
- 工作室会自动播放 FX，并且不把它算进动画按钮。
- 只给描述里写到的动态做特效：滴落（drip）、剥落（flake）、冒烟（puff）、鼓动（pulse）、抖动（jitter）、摆动（sway）。

## 已知做不到的

- 描述里的头部抽搐之类需要动关节，不能放进 FX。要在汇报里说明，留给游戏里的身体动画。
