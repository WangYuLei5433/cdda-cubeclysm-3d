# Cubeclysm 设计与约束

本文是 cdda-cubeclysm-3d 的现行标准，适用于库里每一个 Cubeclysm 模型和每一份贡献。早期的讨论稿见 [proposal.zh.md](proposal.zh.md)，与本文冲突时以本文为准。生成工具 `tools/cubeclysm/` 和 Cubeclysm 技能（`.claude/skills/cubeclysm/`）都按本文执行。

## 1. 定位

- **一个 CDDA id 对应一个模型。** 每个模型的外观照官方描述做，大小照官方体积做。
- **素材库不含引擎代码。** 各引擎读取 `meshset.json` 和 `.glb`，用工作室 cdda-voxel-studio 预览和检查。
- **严格映射。** 素材集声明 `"match": "exact"`，只绑定精确 id，不经 `looks_like` 或内置类型扩散到其他对象。宁可缺模型，也不拿近似的凑数。描述几乎相同的两个 id 也各做一个模型，在徽章、配色等细节上区分。

## 2. 技术规范

| 项目 | 规则 |
|---|---|
| 单位 | 1 单位 = 1 格 = 1 米 |
| 坐标轴 | +Y 向上，脸朝 −Z（北）。工作室的「正面」相机看向 +Z，所以在那里看到的是背面，这是正常的。 |
| 原点 | 脚底中心，立在 y = 0。四足时手脚都着地，拖地的部件也要触地，误差在几厘米以内。 |
| 文件 | 每个模型一个 `.glb`（glTF 2.0，不压缩），按 CDDA id 命名；旁边放一张 4 倍放大的贴图集 `.png`，方便重绘。 |
| 贴图 | 每个模型一张贴图集，最近邻采样，不烘焙光照或阴影。脸部用 128 px 的画布，身体约 160 px/米。 |
| 骨骼 | `root` › `body` › `head`；`body` › `shoulders` › `upper_arm.L/R` › `forearm.L/R` › `hand.L/R`；`body` › `thigh.L/R` › `shin.L/R`（脚是挂在小腿上的方块）。所有部件都是挂在关节上的刚体方块，可以直接做刚体动画。 |
| 身体动画 | 目前还没有，排在开发计划的最后阶段（人形丧尸全部完成之后）。动画名定为 `Idle`、`Walk`、`Attack`、`Death`。描述里的抽搐、痉挛等届时补做。 |
| 特效动画 | 一个名为 **`FX`** 的循环 glTF 动画，周期 2.4 s，**只动 `fx_*` 节点，绝不动关节**，引擎可以把它叠在任何身体动画上，也可以不播放。 |
| 面数 | 只作参考：丧尸约 200–500 面，骷髅类约 1000 面。 |
| 署名 | 每个 `meshset.json` 条目都写 `author`、`license`、`source`。 |

## 3. 体积与体型（以 CDDA 官方数据为准）

CDDA 的怪物 `volume` 决定大小等级（`src/monstergenerator.cpp`）：

| 等级 | 体积 |
|---|---|
| tiny | ≤ 7.5 L |
| small | ≤ 46.25 L |
| medium | ≤ 108 L |
| large | ≤ 483.75 L |
| huge | 更大 |

模型的方块总体积按与 `mon_zombie`（62.5 L）的比例对齐官方体积：

| 体型 | 目标倍数 | 例子 |
|---|---|---|
| child | 0.5× | 31.25 L |
| female / teen / lanky | 约 0.8–1.0× | |
| standard | 1.0× | 绝大多数丧尸 |
| tough | 约 1.15–1.3× | 72.5 L 的凯夫拉丧尸兽 |
| fat | 1.5× | 93.75 L |
| brute | 1.6×（四足时 2.24×） | 100 L / 140 L |
| bloated | 1.75× | 108.5 L |
| giant | 14× | 875 L |

- **体积比在约 0.75–1.45 之间算合格。** CDDA 的体积不算衣物，所以穿戴物多的模型会偏高；骷髅类本来就有空隙，会偏低。超出这个范围要在提交说明里写理由。
- **按体积选体型，不看名字。** 比如锈拳丧尸兽（hammer hands）名字里有「brute」，但官方体积只有 62.5 L，所以用普通体型。

## 4. 风格：Cubeclysm

Unturned 式的方块低模：方块做形体，2D 贴图画细节。远看能靠剪影认出是谁，近看靠贴图和 3D 小部件讲故事。

- **头大颈短。** 方头，头宽约为躯干的 0.76，脖子 2 cm，宽度是头的 0.62。这是有意设计的玩具感，不按真人比例。
- **连指手套式方块手**，不分手指。四肢和躯干都是长方体，标准成人身高约 1.75–1.8 m，腿不要太长。
- **脸是乐高式印刷脸。** 由眼、眉、嘴、标记几类部件 PNG 混搭而成，用关键色按色相重新着色。同一批之间表情要各不相同。描述里写了面部变形的，可以移动部件位置（例如眼睛挤到额头），画布上做不出的变形用 3D 部件做。
- **头发是 3D 发型组**（22 种），发型要符合人物身份。
- **服装是 2D 贴图**：领口、口袋、扣子、迷彩、条纹、字母等都画在贴图上。描述里写到的颜色和图案必须照做。颜色可以自由选，但同一批之间要能区分，也要让人一眼看出职业。

## 5. 必须做成 3D 的东西

描述里提到的穿戴物和形体异常，**必须是独立的 3D 方块，不能只改贴图**：

- 帽子、头盔、面罩、护目镜
- 背心、防弹板、背包、气瓶
- 手铐、听诊器
- 肚腩、驼背、肉瘤、囊肿
- 骨甲、骨刺、骨棒、爪子
- 肉管、嵌入身体的垃圾或碎片、阴影丝

部件要大到在默认视距下看得清。

## 6. 特效

只给描述里写到的动态做特效：

| 特效 | 例子 |
|---|---|
| 滴落 | 淤泥、酸液、黑色粘液 |
| 剥落 | 痂片 |
| 冒烟 | 恶臭、毒气、阴影烟雾、蒸汽 |
| 鼓动 | 肚子、囊肿、肉管 |
| 抖动 | 碎片 |
| 摆动 | 阴影丝、垂挂的肌肉条 |
| 火焰 | 燃烧中的身体（发光的火苗，往上窜、闪烁后熄灭） |

特效粒子挂在它产生的部位上，会跟着该部位动。需要动关节的效果（比如头部抽搐）不放进 FX，留给身体动画。

**恶魔类的角**：恶魔类怪物（目前是恶魔丧尸 `mon_zombie_fiend`）按用户要求加 3D 角和火焰，即使官方描述里没写；在配方注释里注明这是偏离官方的地方。角的大小跟着体型走，体型越大角越大、造型越夸张（造型见工具箱的 `horns`）。

## 7. 核对与检查（每个模型都要做）

1. **生成前**：核对官方描述、官方中文名、体积和大小等级。脚本：`.claude/skills/cubeclysm/scripts/cdda_check.py <id>`。
2. **生成后**：检查体积比和最低部件（是否贴地）。用同一个脚本。
3. **渲染检查**：在工作室里看 3/4 正面和头部特写，确认描述里的每个特征都看得清，没有穿模或悬空。脚本：`scripts/preview.mjs`。

官方数据以工作室使用的 CDDA 版本为准（`public/data/cdda/<version>/catalog.json`，记录了 commit）。
